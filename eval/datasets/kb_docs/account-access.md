# Account Access

If you cannot sign in, use the "Forgot password" link on the sign-in page. We send
a reset link to the email on file; the link is valid for 60 minutes. For your
security, support cannot set or read your password.

If you no longer have access to the email on file, support can start an identity
verification so you can recover the account. This is handled by a human agent, not
over automated chat, because it needs identity checks.

To change the email on your account, sign in and update it on the Profile page. A
confirmation is sent to both the old and the new address.

Two-factor authentication can be turned on from the Security page. If you have
lost your second factor, account recovery is handled by a human agent.
