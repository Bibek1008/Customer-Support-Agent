# Olist historical dataset demonstration

This profile describes the Brazilian E-Commerce Public Dataset by Olist,
distributed through Kaggle. The released marketplace records cover the
2016–2018 period and are historical research data. The application is an
independent demonstration and is not affiliated with Olist. The dataset is
licensed CC BY-NC-SA 4.0; attribution, non-commercial use and share-alike
conditions apply. Check the Kaggle source page for current terms before reuse.

This dataset contains marketplace transactions and post-purchase reviews. It
does not contain customer-support chats or customer-agent transcripts. This
document describes dataset scope; it is not an approved store support policy.
Only conversations actually generated by users of this application are stored
in the application's support conversation/message tables. No historical chats
are synthesized from Olist records.

The demo can summarize recorded order status, purchase/delivery dates, order
items, product categories, payment entries, and review scores where those fields
exist. Demo account and order/product references are generated opaque aliases.
The public dataset does not supply customer authentication. Selecting one of the
curated demo accounts grants access to its historical sample records in that
conversation only.

Recorded order statuses are dataset values, not current carrier statuses. This
data does not provide live shipment tracking, live inventory or prices, a real
support agent, or instructions for taking action. Refund, cancellation,
shipping-change, return, warranty, and seller-contact policies are not provided
by this demonstration. Review scores and dates, if imported, are optional
historical customer-feedback records held separately in `olist_demo.reviews`.
Free-text review comments, geolocation, customer postal codes, and seller postal
codes are excluded from the initial import and are not part of the support
policy knowledge base.
